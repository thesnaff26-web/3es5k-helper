3ЭС5К — учебный интерактивный 3D-макет

Откройте index.html в браузере с интернетом (библиотека Three.js загружается из CDN).
Для GitHub Pages загрузите index.html в корень репозитория.

Реализовано: три секции, наружный вид, крыша, режим разреза, кабины, условные аппаратные шкафы, выбор узлов, вращение/масштабирование, открытие дверец.

ВАЖНО: Это НЕ точная заводская модель 3ЭС5К и НЕ руководство по эксплуатации. Геометрия и расположение оборудования схематические. Нельзя использовать для управления реальным локомотивом, переключения кранов, установки перемычек или диагностики.
